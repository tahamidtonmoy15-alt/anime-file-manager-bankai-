# Anime Library APK

1. GitHub-এ নতুন repo বানাও এবং এই ফোল্ডারের সব ফাইল (লুকানো `.github` সহ) upload করো।
2. repo → **Actions** → **Build APK** → **Run workflow** (push করলেও নিজে চলে)।
3. ৫–১০ মিনিট পর সবুজ ✔ হলে রান খুলে নিচে **Artifacts → anime-library-apk** নামাও।
4. ZIP খুলে `app-debug.apk` ফোনে install করো (Unknown sources চালু করতে হতে পারে)।
5. অ্যাপে Episode-এর পাশে **⤴** চাপলে MX Player / VLC / Mi Video-র "Open with" তালিকা আসবে।
